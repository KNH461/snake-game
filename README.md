# 🎮 小游戏合集

GitHub Pages 部署地址: https://KNH461.github.io/snake-game/

## 文件说明

- `index.html` - 游戏大厅（游戏入口 + 全局排行榜 + 个人进度）
- `snake.html` - 贪吃蛇（4档速度 + 得分倍率系统 + 排行榜）
- `tetris.html` - 俄罗斯方块（触屏D-pad + 排行榜）
- `adventure.html` - 文字冒险 RPG（完整RPG系统，见下方）

## 文字冒险 RPG 功能清单

### 账号系统
- 注册/登录（用户名+密码，SHA-256加密）
- 云端存档（jsonbin.io），换设备可恢复
- 自动登录（7天会话）
- 手动/自动保存（30秒）

### 装备系统
- 8个部位：武器/头盔/护腕/胸甲/腿甲/鞋子/项链/戒指
- 6种品质：白色(普通)/绿色(优秀)/蓝色(稀有)/紫色(史诗)/橙色(传说)/红色(神话)
- 装备生成：属性随等级和品质缩放

### 升级系统
- 经验公式：level × 100
- 升级回满血 + 攻防成长

### 地图系统（全部开放）
- 翡翠草原 Lv.1-5
- 暗影森林 Lv.5-15
- 熔岩洞穴 Lv.15-30
- 冰霜山脉 Lv.30-50
- 深渊裂隙 Lv.50-75
- 魔王领域 Lv.75-100

### 战斗系统
- 每2秒自动战斗
- 暴击系统（基础5% + 装备加成）
- 死亡扣5%金币，自动半血复活
- 脱战回血（每3秒5%最大HP）

### 宝箱系统
- 铁箱(100金)/银箱(500金)/金箱(2000金)/钻石箱(10000金)
- 钻石箱15%出宠物

### 宠物系统
- 最多4只，上阵1只
- 加成：攻击%/防御%/生命%/经验%/金币%/暴击%

### 强化系统
- +1~+10，每级+10%属性
- 成功率：100%/95%/85%/75%/60%/45%/30%/18%/10%/5%
- 失败降1级

### 重铸系统
- 重新随机装备属性
- 消耗金币 + 重铸石

### 材料系统（14种）
- 各地图专属材料 + 通用强化石/重铸石
- 背包分类：全部/装备/材料
- 点击材料查看使用说明
